# nMolecules Bricks Extensions Runtime

`NMolecules.Bricks.Extensions.Runtime` contains optional runtime and visibility
evidence types for Bricks.

## Included Areas

- `Runtime` for dependency registrations, runtime activations and runtime
  wiring evaluation.
- `Reflection` for reflection-access evidence and policy evaluation.
- `Visibility` for friend-assembly and visibility evidence.

Use this package when a tool needs runtime, reflection or visibility evidence
that can feed deterministic Bricks policies.
