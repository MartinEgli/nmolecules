# nMolecules Bricks Extensions Core

`NMolecules.Bricks.Extensions.Core` contains lightweight operational helpers
that compose the core Bricks model without runtime, assessment or reporting
dependencies.

## Included Areas

- `Configuration` for deterministic configuration source precedence and
  resolution.
- `Profiles` for built-in architecture profiles that compose Bricks roles,
  rules and policies.

Use this package when a tool needs profile or configuration support but does
not need runtime evidence, adoption workflows, dashboards or report formats.
