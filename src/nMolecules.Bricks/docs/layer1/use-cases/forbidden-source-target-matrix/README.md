# Forbidden Source-Target Matrix

Layer: 1 - Core  
Parent use case: `../uc-l1-18-forbidden-source-target-matrix.md`

This directory contains the fully granular split of the forbidden
source-target matrix.

Organization:

- one folder per source shape
- one file per source-target combination
- 9 source folders
- 81 combination files
