# nMolecules Bricks Extensions Reporting

`NMolecules.Bricks.Extensions.Reporting` contains exchange documents,
projection helpers and final report formats for Bricks tooling.

## Included Areas

- `Adoption` for baselines, suppressions and violation state projection.
- `Export` for dependency graphs, role maps and resolution traces.
- `IO` for JSON file helpers around Bricks documents.
- `Reports` for report documents, JSON reports and SARIF reports.

Use this package when a tool needs durable report files, adoption workflows or
export documents.
