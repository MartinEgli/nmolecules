# nMolecules Bricks Extensions Assessment

`NMolecules.Bricks.Extensions.Assessment` contains maturity, coverage and
planning models for Bricks adoption.

## Included Areas

- `Benchmarking` for performance budgets and benchmark reports.
- `Conformance` for capability and conformance-level assessment.
- `Dependencies` for dependency coverage targets and reports.
- `Governance` for governance area assessment.
- `Roadmap` for staged adoption planning.

Use this package when a tool needs to explain, measure or plan Bricks adoption.
It does not decide analyzer diagnostics.
